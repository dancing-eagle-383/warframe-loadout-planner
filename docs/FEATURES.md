# Warframe Loadout Planner — feature reference

A loadout planner workspace for Warframe, built around equipment groups and build comparisons, with activity notes kept in a separate reference area.

| Section | Description |
|---|---|
| Equipment groups | Equipment categories and the associated selection or configuration options. |
| Build comparisons | A dedicated section for build comparisons and the configuration details associated with that area. |
| Activity notes | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
